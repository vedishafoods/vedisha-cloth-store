# Vedisha Cloth Store

A beautiful, responsive website for ladies and kids cloth store built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Product Catalog**: Showcase ladies and kids clothing items
- **Shopping Cart**: Add items to cart with local storage persistence
- **WhatsApp Integration**: Direct customer communication via WhatsApp
- **UPI Payments**: Integrated payment gateway support
- **Contact Form**: Customer inquiry form with email integration
- **Beautiful UI**: Modern design with smooth animations and transitions

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Add your company logo and product images
4. Update contact information and WhatsApp number
5. Configure UPI payment details
6. Deploy to GitHub Pages or your hosting

## Customization

### Update Company Info
- Replace logo.png with your company logo
- Update navigation links and menu items
- Modify color scheme in CSS

### Add Products
- Add product images to the `images/` folder
- Update the product details in the HTML products section
- Modify pricing and available grades

### Configure Payments
- Update UPI_ID in the JavaScript section
- Add your WhatsApp Business number (WA_BUSINESS_NUMBER)
- Configure payment settings

## Technologies Used

- HTML5
- CSS3 (with media queries for responsiveness)
- Vanilla JavaScript (no dependencies)
- Local Storage API
- QR Code API (for UPI QR generation)
